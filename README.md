# 🛒 Sistemas de Vendas em Delphi

Sistema de Vendas desenvolvido em **Delphi (Object Pascal)** com foco no controle de clientes, produtos, vendas e relatórios.  
O projeto foi criado com o objetivo de estudo/aprimoramento e pode ser adaptado para uso comercial.


## Funcionalidades

- Cadastro de pessoas
- Cadastro de cidades
- Cadastro de empresas
- Controle de estoque
- Registro de vendas
- Cálculo automático de valores e totais
- Emissão de relatórios
- Integração com banco de dados

## Tecnologias Utilizadas

- **Delphi** (RAD Studio / Community Edition)
- **Object Pascal**
- **FireDAC** para acesso a dados
